Reports instruction mnemonics that GNU as would not recognise for an AArch64 target.

Condition suffixes (b.eq) and the 2 upper-half SIMD forms (saddl2) are accepted, as are macros defined in the same file with .macro or #define and register aliases introduced with .req.

The instruction set covered here is broad but not exhaustive; if your toolchain accepts a mnemonic this inspection rejects, turn the inspection off rather than changing working code.
