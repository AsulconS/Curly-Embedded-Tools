Sets up GDB Python API stubs for the directory holding the GDB script under the caret: writes the bundled gdb.pyi there and marks that folder as a source root, so that import gdb resolves inside its python … end blocks.

Both halves are needed. GDB’s gdb module exists only inside the Python interpreter that GDB embeds and is not installable from anywhere, so a stub is the only way it can resolve; and an injected fragment’s file is a window into the host document rather than a file on disk, so the sibling-module rule that would normally find that stub does not reach it — the directory has to be on the Python path.

Each half is skipped if it is already in place. The source-root marking is stored in the project model, so a project whose roots are generated by an external build (Gradle, for instance) will lose it on the next re-import.
